# Security Architecture

## Threat model

| Asset | Threats | Controls |
|---|---|---|
| Local API | other local processes, malicious web pages (CSRF, DNS rebinding) | loopback binding; **Host header allow-list** (`127.0.0.1`, `localhost`); **Origin check** on state-changing requests; a session cookie `SameSite=Strict`, `HttpOnly`, set on first load from the same origin |
| MCP channel | prompt-injected agent instructions | narrow tools; permission checks in the API; high-impact actions refused for `mcp`; audit |
| Host agent | command injection | fixed endpoints, no shell, argument lists built from validated specs; token; loopback only |
| Files | path traversal, zip-slip, malicious images and SVG, decompression bombs | storage keys generated by the server; export targets limited to user-approved roots; MIME sniffing + Pillow decode with pixel limits; SVG sanitized (allow-list elements, no scripts, no external refs); size limits |
| Workflows | malicious imported workflow JSON | schema validation; only known node types allowed; the workflow cannot name file paths outside model folders |
| Models | tampered downloads | SHA-256 against the catalogue; HTTPS only |
| Data | loss, corruption | append-only audit; immutable versions; verified backups |
| Supply chain | compromised dependencies | lock files, Dependabot, `pip-audit`, `pnpm audit`, CodeQL, secret scanning |

## Tokens

These are generated at setup and stored in `.env` (git-ignored) and the database:
- API session secret;
- MCP token (rotatable);
- worker token;
- host agent token.

They are never logged.

## Licensing posture

- The application is Apache-2.0.
- ComfyUI (GPL-3.0) and its custom nodes run as separate processes reached over HTTP; none of their code is linked or vendored.
- Model weights are never committed or redistributed; the catalogue only references sources.
