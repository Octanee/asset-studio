# User Stories

| ID | Story | UC | FR |
|---|---|---|---|
| US-001 | As a user, I want to describe a project to Claude Code and get a draft configuration I can edit, so I do not have to fill every field by hand. | UC-002 | FR-008 |
| US-002 | As a user, I want to define a style from example images, so all assets look the same. | UC-004 | FR-011 |
| US-003 | As a user, I want to define a character once and reuse it, so the same person appears in every illustration. | UC-005 | FR-015 |
| US-004 | As a user, I want to set the exact body pose, so an exercise is shown with the correct position. | UC-006 | FR-020–FR-022 |
| US-005 | As a user, I want to queue a batch of illustrations and come back later, so long generations do not block me. | UC-008 | FR-034, FR-040 |
| US-006 | As a user, I want to approve or reject each version, so only good images reach my product. | UC-009 | FR-061 |
| US-007 | As a user, I want regeneration never to overwrite what I approved, so I can experiment safely. | UC-010 | FR-052 |
| US-008 | As a user, I want to export approved images into my app's folder with one preset, so publishing is repeatable. | UC-011 | FR-090–FR-094 |
| US-009 | As a user, I want to train a LoRA of my character, so consistency improves over time. | UC-012 | FR-070–FR-075 |
| US-010 | As a user, I want to see each model's licence against my project's intended use, so I make an informed decision. | UC-013 | FR-083 |
| US-011 | As a user, I want Claude to comment on images without being able to approve them unless I allow it, so I stay in control. | UC-009 | FR-064 |
| US-012 | As a user, I want to back up and restore my work, so I do not lose it. | UC-016 | FR-111, FR-112 |
| US-013 | As a user, I want to create simple icons as SVG, so I do not need diffusion for flat graphics. | UC-014 | FR-045 |
