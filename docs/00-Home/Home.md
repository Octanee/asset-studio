# Universal Asset Studio — Documentation

Universal Asset Studio is a local-first, open-source (Apache-2.0) application for creating, organizing, reviewing and exporting visual assets with locally hosted AI models. It supports many independent projects, each with its own styles and recurring characters.

> This vault is the **source of truth** for approved requirements and decisions. Business scope was approved on 2026-11-21 and the documentation baseline on 2026-11-22.
